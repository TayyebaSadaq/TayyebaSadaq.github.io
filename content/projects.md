# Projects
## Explainable AI Diabetes Diagnosis Tool
*Dissertation · React, Python, Flask, Git*

My final year dissertation project. I built a machine learning model that classifies diabetes risk from healthcare datasets, achieving 75%+ accuracy — but the interesting part was the explainability layer. I implemented SHAP and LIME techniques so the model could show why it reached a conclusion, not just what it concluded. That principle — transparent, evidenced reasoning — maps directly onto how I think about forensic investigation. The project has a Python/Flask backend, a React frontend, and a full API layer.

[View on GitHub](https://github.com/TayyebaSadaq/diabetes-prediction-dissertation)

## MiniLang Interpreter
*Python*

I built a programming language interpreter from scratch in Python. MiniLang supports variables, loops, lists, and more. It's one of those projects that sounds intimidating until you start — and then you can't stop. Building it forced me to deeply understand how code is parsed, evaluated, and executed, which gave me a much stronger mental model for how malicious code works at a low level.
